# Architecture Skill

## Purpose
Keep the system modular, simple and production-ready.

## Rules
- Prefer modular monolith.
- Avoid premature microservices.
- Avoid SPA unless required.
- Keep dependencies directional.
- Record meaningful architecture decisions.

## Do Not
- create abstractions without use
- add services solely for fashion
- introduce API unnecessarily

## Workflow
Inspect -> plan -> implement -> test -> document.

## Quality Checklist
- clear boundaries
- no circular dependencies
- testable application services
- deployment simplicity

## Definition of Done
Architecture is documented and validated by build/tests.
