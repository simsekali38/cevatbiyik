# Phase Order

1. 00-discovery.md — Discovery, repository audit, hosting/runtime verification, open questions and baseline.
2. 01-foundation.md — Create solution structure, documentation, coding standards, configuration and environments.
3. 02-domain-database.md — Implement domain model, EF Core, MySQL 8, migrations, indexes and seed strategy.
4. 03-identity-admin-foundation.md — Implement Identity, admin area, authorization, audit logs and dashboard foundation.
5. 04-cms.md — Implement pages, profile, practice areas, articles, categories, tags and FAQ CMS.
6. 05-media-files.md — Implement media library, secure uploads, image processing and document storage.
7. 06-public-site.md — Implement public Razor site, Bootstrap design system, responsive layouts and accessibility.
8. 07-seo.md — Implement SEO metadata, canonical, schema, sitemap, robots, redirects and automated SEO checks.
9. 08-local-seo.md — Implement Kayseri/local content architecture and local SEO features without doorway pages.
10. 09-contact-analytics.md — Implement contact forms, anti-spam, email notifications and analytics/GTM event architecture.
11. 10-security-hardening.md — Perform security hardening, headers, rate limiting, validation, upload review and dependency audit.
12. 11-testing.md — Implement unit/integration/E2E tests and regression suite.
13. 12-performance-accessibility.md — Measure and improve Core Web Vitals and WCAG 2.2 AA compliance.
14. 13-plesk-deployment.md — Prepare production publish, Plesk configuration, environment, MySQL, uploads, HTTPS and backups.
15. 14-production-audit.md — Run full production readiness audit and fix blockers.
16. 15-launch.md — Final launch checklist, monitoring, backup/restore verification and post-launch documentation.
